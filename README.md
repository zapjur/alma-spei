## 🛠️ Stos technologiczny

Projekt zostanie zbudowany przy użyciu stosu technologicznego opartego na ekosystemie Clojure, zapewniającego pełną spójność językową między frontendem a backendem.

💻 Języki i Frameworki

* **Clojure** – Backend odpowiedzialny za parsowanie wyciągów bankowych/plików 1,5% oraz logikę deduplikacji rekordów.

* **ClojureScript** – Frontend obsługujący reaktywny interfejs weryfikacji danych (ekran porównywania różnic Side-by-Side).

🗄️ Baza danych i Przechowywanie

* **PostgreSQL** – Relacyjna baza danych zapewniająca pełną transakcyjność operacji (fundament pod bezpieczne cofanie importów / Rollback) oraz mechanizmy wyszukiwania rozmytego.

🚀 DevOps i CI/CD

* **GitHub Actions** – Zautomatyzowany potok CI/CD wykonujący testy integracyjne parserów oraz automatyczny deploy aplikacji.

🎨 Design & UI/UX

* **Figma** – Projektowanie makiet przepływu importu danych oraz weryfikacja ergonomii interfejsu z pracownikami hospicjum.
